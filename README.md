# Planta fabricadora de vidrio

Simulación interactiva en HTML del proceso de vidrio plano, basada en una maqueta de 60 × 30 cm con 10 estaciones: silos, tolva, horno de fusión, baño de estaño, recocido (lehr), control de calidad, corte y embalaje, almacén, oficinas y reciclaje de casco.

Abre `index.html` en el navegador o visita la versión publicada en GitHub Pages:
https://protocol-pixel.github.io/Planta-fabricadora-de-vidrio/

Los valores de la simulación son referenciales y tienen fines didácticos.
